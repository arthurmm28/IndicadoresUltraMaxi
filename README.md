## Publicação
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Abra Settings > Pages.
4. Em Build and deployment, selecione a branch principal e `/root`.
5. Salve e aguarde a URL do GitHub Pages.

## Observação importante
O login é uma barreira no front-end. Como o projeto é estático, as credenciais podem ser descobertas por alguém que inspecione o código. Para segurança real, utilize autenticação em backend/serviço de identidade.

O Power BI também precisa permitir o acesso do usuário. Se o relatório exigir conta/permissão Microsoft, o usuário continuará sujeito às permissões configuradas no Power BI.

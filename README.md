# Análise de indicadores Ultra Popular - Maxi Popular

Site estático para GitHub Pages com tela de login e relatório Power BI.

## Credenciais configuradas
- Usuário: 81
- Senha: 062395

## Publicação no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Vá em Settings > Pages.
4. Em Source, selecione a branch principal e a pasta `/root`.
5. Salve e aguarde a publicação.

## Importante sobre segurança
Como este site é estático e hospedado no GitHub Pages, a validação do usuário e da senha acontece no navegador. Isso NÃO é uma autenticação de segurança real: alguém com conhecimento técnico pode visualizar as credenciais no código.

Além disso, o relatório Power BI precisa estar acessível para o usuário no navegador. Se o relatório exigir login/permissões da Microsoft, o visitante ainda precisará estar autorizado no Power BI.

Para proteção real, é necessário colocar a autenticação em um backend/serviço de identidade e usar um método de incorporação do Power BI apropriado.
